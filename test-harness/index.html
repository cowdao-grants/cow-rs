Loads crates/cow-sdk-wasm/pkg/cow_sdk_wasm.js and exercises the Rust SDK from the browser. Built with --features in_shim_signing so the ECDSA panels work. Start with just wasm-harness then open http://localhost:8765/test-harness/.

3. eip712_payload — cross-library digest parity

    

      Builds the canonical typed-data input via the shim's
      eip712_payload, then hashes it independently with
      viem's hashTypedData, ethers' TypedDataEncoder,
      and the shim's own order_struct_hash +
      eip712_message_hash path. All three must match byte
      for byte. (Cow SDK parity follows transitively: its
      hashTypedData delegates to ethers' encoder.)

      Signs the same payload three different ways and asserts

        shim only builds the payload via eip712_payload and consumes
        the signature via build_order_creation. Signatures
        produced by the same account match across all three.
